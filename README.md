# my-site — האתר האישי של HODY

אתר אישי סטטי בעברית (RTL) שנבנה כחלק מקורס 10x.
האתר כולל ארבעה אזורים: היכרות, רקע, נושא מרכזי (בניית אפליקציות עם AI ו-Claude Code) ויצירת קשר.

## איך פותחים את האתר מהתיקייה

האתר בנוי מ-HTML, CSS ו-JavaScript בלבד — **אין צורך בהתקנות, בשרת או בספריות חיצוניות**.

1. מורידים או משכפלים את התיקייה למחשב.
2. לוחצים לחיצה כפולה על הקובץ `index.html` (או גוררים אותו לחלון הדפדפן).
3. זהו — האתר נפתח.

## מבנה התיקייה

| קובץ / תיקייה | תפקיד |
|---|---|
| `index.html` | תוכן העמוד וכל ארבעת האזורים |
| `style.css` | העיצוב, כולל תמיכה רספונסיבית ומצב כהה |
| `script.js` | מצב כהה ובדיקת תקינות של טופס יצירת הקשר |
| `images/` | תמונות ואיורים של האתר |
